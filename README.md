# 🛡️ Hacker-Toolkit-01

我的个人网络安全测试工具库，用于合法授权环境下的安全测试与漏洞挖掘。

## 🚀 最新战绩 (Changelog)
*   **[2026-11-04]** 成功发掘并提交首个真实企业级逻辑漏洞（FLIPOS收银系统后台验证码校验失效导致可爆破，定级：中危）。
*   **[2026-11-03]** 完成底层核心武器库搭建，包含自动化信息收集与并发处理模块。

## 🛠️ 包含工具
*   `dir_scan.py`：基于多线程的高效目录扫描器，内置常见敏感路径字典。
*   `js_finder.py`：前端 JS 源码信息提取工具，自动挖掘隐藏的 API 接口。
*   `brute.py`：多线程表单弱口令检测脚本。
